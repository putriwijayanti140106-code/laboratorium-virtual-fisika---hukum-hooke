# HookeLab — kerangka baru

1. Ekstrak folder `HookeLab`.
2. Buka folder tersebut di VS Code.
3. Jalankan `index.html` dengan browser atau ekstensi Live Server.
4. Gunakan sidebar untuk berpindah halaman.

## Struktur
- `index.html`: Beranda baru
- `petunjuk.html`: Petunjuk Praktikum
- `modul.html`: Daftar modul (Mode 1 sengaja belum dibuat)
- `lkpd.html`: Kerangka LKPD Digital
- `evaluasi.html`: Kerangka evaluasi
- `style.css`: Sistem desain bersama
- `js/common.js`: navigasi responsif dan pencarian sederhana
- `js/home.js`: script khusus beranda
- `assets/`: tempat logo dan ilustrasi dapat ditambahkan

Mode 1 ditunda sesuai kesepakatan. Kartu modul saat ini hanya berstatus “Segera tersedia”.
